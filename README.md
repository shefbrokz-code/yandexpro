# Y-Pro

Android-помощник водителя такси. Когда в водительском приложении появляется предложение заказа,
Y-Pro читает с экрана цену, подачу и длину поездки, учитывает комиссии, топливо, износ и пробки
и показывает сверху цветную плашку:

> 🟢 **3 420 ₸/ч**
> чистыми 1 850 ₸ · 32 мин · 14,2 км

Цвет плашки зависит от порогов в настройках: зелёный — выгодно, жёлтый — так себе, красный — невыгодно.

## Как это работает

| Шаг | Где в коде |
| --- | --- |
| Сервис специальных возможностей получает события от водительского приложения и собирает тексты экрана | `app/.../service/OrderReaderService.kt`, `ScreenText.kt` |
| Из текстов достаются цена, расстояния и время | `core/.../OrderParser.kt` |
| Скорость по городу с пробками заранее обновляется в фоне каждые 2 минуты по 7 магистралям Алматы через 2GIS | `app/.../traffic/`, `core/.../TrafficModel.kt`, `Corridors.kt` |
| Расчёт: цена − комиссии − налог − топливо − износ, делённое на время подачи + поездки + ожидания | `core/.../EarningsCalculator.kt` |
| Плашка поверх экрана (не перехватывает нажатия) | `app/.../overlay/OverlayBanner.kt` |

Пробки подгружаются **заранее**, поэтому в момент заказа сеть не нужна: оценка занимает миллисекунды.
Если время подачи или поездки видно на экране, используется оно. Если нет — время считается
по текущей скорости из 2GIS. Если 2GIS недоступен больше 10 минут, берётся типичная скорость
Алматы для этого часа и дня недели.

## Модули

- `core` — чистый Kotlin без Android: разбор экрана, расчёт, модель пробок. Покрыт unit-тестами.
- `app` — Android-приложение: сервис, плашка, клиент 2GIS, экран настроек (Jetpack Compose).

## Сборка

1. Откройте проект в Android Studio (нужен JDK 17+).
2. Добавьте ключ 2GIS в `local.properties` (файл не попадает в git):
   ```
   TWOGIS_API_KEY=ваш_ключ
   ```
   Ключ выдаётся в кабинете разработчика 2GIS (нужен доступ к Routing API). Без ключа приложение
   работает на типичных скоростях по времени суток.
3. `./gradlew :app:assembleDebug` — APK будет в `app/build/outputs/apk/debug/`.
4. Тесты ядра: `./gradlew :core:test`.

## Первый запуск на телефоне

1. Установите APK и откройте Y-Pro.
2. «Открыть спец. возможности» → Y-Pro → включить.
   На Android 13+ для приложений не из Play Маркета пункт может быть серым: откройте
   «Настройки → Приложения → Y-Pro → ⋮ → Разрешить ограниченные настройки» и повторите.
3. Укажите свои комиссии, цену топлива, расход и пороги цветов, нажмите «Сохранить».

## Заказы без конечного адреса

Если на экране есть признак такого заказа (по умолчанию «без конечн», «без адреса», «адрес не указан»),
найденные расстояние и время считаются подачей, а поездка берётся из настройки «Поездка без адреса, км»
(по умолчанию 6 км). На таких заказах на экране обычно минимальная цена, поэтому, если задан тариф
(посадка, ₸/км, ₸/мин), цена считается как большее из цены на экране и расчёта по тарифу.

Плашка помечается знаком «≈» и строкой «адрес не указан · считаю 6 км», чтобы было видно,
что это прикидка. Подача при этом считается точно.

## Настройка распознавания заказа

Разметку экрана водительского приложения мы пока не видели на реальных заказах, поэтому разбор
сделан по общим правилам: цена — самое большое число с «₸»/«тг», первое расстояние — подача,
второе — поездка. Экран считается заказом, только если на нём есть слово из списка
(по умолчанию «Принять»).

Чтобы подогнать распознавание под реальный экран:

1. Включите «Сохранять текст экрана» в разделе «Отладка».
2. Дождитесь предложения заказа.
3. Нажмите «Скопировать последний экран» и пришлите текст разработчикам.
   По нему дописывается правило и тест в `core/src/test/.../OrderParserTest.kt`.

## Важно

- Распространение — через свой сервер, не через Google Play: Play ограничивает приложения,
  которые используют специальные возможности не для помощи людям с ограничениями.
- Использование сторонних инструментов может противоречить правилам сервиса такси.
  Y-Pro только показывает оценку и ничего не нажимает за водителя.
